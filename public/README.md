# Public privacy policy

`privacy.html` is intentionally isolated from the private product documents. The GitHub Pages workflow deploys this folder only; it never publishes the repository root or `/docs`.

The intended public policy URL is:

`https://ronanrocking.github.io/FreeFeed/privacy.html`

After pushing this workflow, set the repository's Pages source to **GitHub Actions**, wait for the deployment to finish, verify this URL opens publicly, and enter it in the Chrome Web Store **Privacy** tab.
